# Ship60

A referral-powered registration engine for NxtWave's free workshop
**"Build Your First AI Project in 60 Minutes"**. Built on Cloudflare Workers
(Static Assets, D1, KV, Durable Objects, Workers AI, Turnstile, Cron).

> **Simulation notice.** This project is a growth-challenge simulation. No real
> students are contacted. All demo data generated by the seed scripts is labelled
> `is_simulated = 1` and shown with a visible **"Simulated data"** label in the
> admin war room and `/plan`. Never present simulated numbers as real results.

## What's inside

- Landing page with an AI-generated project preview, inline registration, Turnstile
- Referral links with server-rendered OG previews and share cards (PNG)
- My Launchpad: seat ticket, referral link, WhatsApp/LinkedIn sharing, reward tiers
- Student and college leaderboards
- Admin war room: pacing vs plan, funnel, channels, ambassadors, flags, daily brief
- Live workshop room (Durable Object + WebSockets): check-in, polls, quiz, help queue
- AI project evaluator with prompt-injection-safe framing + verifiable certificates
- `/plan` growth deck (5 slides, print-to-PDF) and `/build` architecture notes
- Deterministic simulator + seed scripts for demo data

## Setup

```bash
npm install
npm run db:migrate:local     # apply D1 migrations locally
npm run dev                  # Vite + Worker dev server
```

Node 20+. Dev Turnstile test keys are already in `wrangler.jsonc`.

## Scripts

```bash
npm run typecheck   npm run lint   npm test   npm run e2e   npm run verify
npm run seed:local  npm run seed:remote -- --confirm   npm run seed:clear
npm run smoke -- --url <base-url>
npm run warm:ideas  # pre-generate the idea cache
```

## Deploy (Cloudflare)

```bash
npx wrangler login
npx wrangler d1 create ship60-db        # paste database_id into wrangler.jsonc
npx wrangler kv namespace create CACHE  # paste id into wrangler.jsonc
npx wrangler d1 migrations apply ship60-db --remote
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put SESSION_SECRET
npx wrangler secret put TURNSTILE_SECRET_KEY
npm run build && npx wrangler deploy
npm run seed:remote -- --confirm
npm run smoke -- --url https://ship60.<subdomain>.workers.dev
```

Create the Turnstile widget for the `workers.dev` hostname and set
`TURNSTILE_SITE_KEY` in `wrangler.jsonc`.

## Simulated-data caveats

Every number produced by `scripts/seed.ts` is fake: colleges are real names but
students are invented, and registrations, check-ins, submissions and evaluations
are generated. The admin war room shows a persistent "Simulated data" banner and
an include/exclude toggle. `/plan` labels the pacing chart. Nothing simulated is
ever presented as a real campaign result.
